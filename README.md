# BT 下载器

一些可以直接食用的小工具，希望给你带来更好的互联网体验。

一个轻量的本地下载工具，桌面端和安卓端共用同一套网页界面。支持磁力链接、`.torrent` 种子文件，以及带 Cookie / 自定义请求头的 HTTP 直链。

## 它解决什么问题

迅雷、各类网盘客户端往往会识别流量来源，对未付费或非官方通道主动限速。运营商有时也会对特定下载协议或热门下载软件做QoS。本项目尽量走标准 BitTorrent 和普通 HTTP 拉取，减少被这些客户端或通道单独限速的情况。

它适合：

- 已有磁力 / 种子，不想再经过迅雷等商业下载器
- 网盘或网站给出了直链，需要自己带 Cookie、Referer 才能下
- 希望任务停掉后还能续传，并自己指定保存目录

## 做不到什么

这不是迅雷那种商业加速器，也不是网盘官方客户端。

- **没有 P2SP**：不会把 HTTP 直链拆成多源、多节点并行拉。一条直链就是一条连接。
- **没有热门资源服务器**：不会连官方 CDN、离线缓存或「热门资源一键满速」那类节点。BT 速度取决于当时有多少人在做种；直链速度取决于源站本身给不给你带宽。
- 冷门种子可能很慢，甚至长时间停在「下载元数据」。源站本身限速时，换成本工具也不会变快。

简单说：它主要是躲开迅雷、网盘客户端和部分运营商针对特定软件的限速，**不是**把下载加速到比官方通道更快。

## 功能

- **磁力链接**、**`.torrent` 文件**、**HTTP / HTTPS 直链**
- 直链可填写 Cookie、自定义 Headers（网盘鉴权、Referer、UA）
- 任务进度、速度、做种/节点数
- 断点续传：BT 用 fastresume，HTTP 用 Range + `.part` 临时文件
- 自定义下载目录（浏览选择文件夹，只影响之后的新任务）
- 关闭后再次打开，会尽量恢复未完成任务
- 桌面端（Windows）和安卓端，界面一致

## 直接下载

编译好的文件在仓库 [`release/`](https://github.com/ZDSPDK/-/tree/main/release) 目录，下载后即可使用：

- Windows：[BT下载器.exe](https://github.com/ZDSPDK/-/raw/main/release/BT下载器.exe)
- Android：[BT下载器.apk](https://github.com/ZDSPDK/-/raw/main/release/BT下载器.apk)

安卓若提示未知来源，在系统设置里允许安装即可。

## 怎么用

### 桌面端

1. 下载并运行 `release/BT下载器.exe`，或在 `desktop` 目录执行 `python app.py`
2. 浏览器会打开本地页面：`http://127.0.0.1:8888`
3. 顶部「浏览」选择下载目录
4. 粘贴 `magnet:` 或 `http(s)://` 链接，或上传 `.torrent`
5. 网盘直链如需登录态，展开「高级设置」，贴上 Cookie / Headers

任务状态写在程序旁边的 `.bt_downloader` 目录；下载文件在你选的目录里。

### 安卓端

安装 `release/BT下载器.apk` 后打开即可，用法和桌面端相同。安卓 11 及以上若要自选存储路径，需要授予「所有文件访问」权限。默认目录是系统下载文件夹下的 `TorrentDownloads`。

## 说明

请只下载你有权获取的内容。本工具不提供资源检索、不托管文件、不做离线下载。

速度完全取决于对端：BT 看swarm，直链看源站。没有会员通道，也没有加速节点。
